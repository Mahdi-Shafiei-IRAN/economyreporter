# economy — سامانه‌ی مدیریت مالی خانواده

یک اپ موبایل (Android/Flutter) + بک‌اند (Django REST) برای مدیریت **دخل و خرج کل خانواده** و **همه‌ی حساب‌ها/کارت‌ها در یک برنامه**.

- تراکنش‌ها به‌صورت خودکار از **پیامک بانکی** استخراج می‌شوند (و ثبت دستی هم دارد).
- معماری **Offline-First**: هر تراکنش از لحظه‌ی ساخت روی گوشی UUID می‌گیرد و در پایگاه محلی ذخیره می‌شود؛ هر وقت اینترنت وصل شد، آنچه هنوز ثبت نشده به سرور sync می‌شود.
- ۳ عضو خانواده، هرکدام چند حساب و کارت؛ داشبورد نشان می‌دهد **چقدر درآمد، چقدر هزینه، هر هزینه بابت چی، از کدام کارت، و چطور**.

## استک

- **بک‌اند:** Django + Django REST Framework + PostgreSQL (کنترل کامل)
- **موبایل:** Flutter + SQLite محلی + Secure Storage
- **سرور فعلی (توسعه):** کامپیوتر خودت روی شبکه‌ی محلی؛ بعداً VPS ایرانی
