# اجرای اپ روی گوشی خودت (سرور = کامپیوتر خودت)

## پیش‌نیاز شبکه
- گوشی و کامپیوتر روی **یک Wi-Fi** باشند.
- IP کامپیوتر: **192.168.1.100** (اگر عوض شد با `ipconfig` ببین؛ بعد یا در
  `mobile/lib/core/config/app_config.dart` عوضش کن یا موقع بیلد
  `--dart-define=API_BASE_URL=http://<IP>:8000/api/v1` بده و دوباره بساز).

## ۱) اجرای سرور روی کامپیوتر
```bash
cd backend
.venv\Scripts\python.exe manage.py migrate
.venv\Scripts\python.exe manage.py runserver 0.0.0.0:8000
```
> `migrate` بعد از هر به‌روزرسانی کد بک‌اند لازم است (مثلاً ستون‌های جدید مالکیت کارت،
> دسته‌ها و حذف نرم). اگر اجرا نشود، همگام‌سازی خطا می‌دهد.

اجازه‌ی عبور فایروال برای پورت ۸۰۰۰ (PowerShell با دسترسی Administrator، یک‌بار):
```powershell
New-NetFirewallRule -DisplayName "Django Dev 8000" -Direction Inbound -LocalPort 8000 -Protocol TCP -Action Allow
```
تست از خود گوشی: در مرورگر گوشی باز کن
`http://192.168.1.100:8000/api/v1/auth/me/` → باید یک JSON با خطای 401 بدهد.
اگر باز شد یعنی گوشی سرور را می‌بیند.

## ۲) نصب APK روی گوشی
- فایل: `mobile/build/app/outputs/flutter-apk/app-arm64-v8a-release.apk`
  (برای بیشتر گوشی‌های امروزی؛ گوشی خیلی قدیمی: `app-armeabi-v7a-release.apk`)
- روش A (کابل USB): حالت Developer + USB Debugging گوشی را روشن کن، سپس:
  ```bash
  adb install -r mobile/build/app/outputs/flutter-apk/app-arm64-v8a-release.apk
  ```
  (adb در `C:\Users\mahdi\AppData\Local\Android\sdk\platform-tools\adb.exe`)
- روش B (بدون کابل): فایل apk را به گوشی منتقل کن (تلگرام/USB/…)، روی گوشی
  «نصب از منابع نامطمئن» را برای فایل‌منیجر مجاز کن و نصب کن.
- به‌روزرسانی روی نسخه‌ی قبلی نصب می‌شود و داده‌ها می‌مانند (دیتابیس گوشی خودکار ارتقا می‌یابد).

## ۳) ورود و اعضای خانواده
کاربر تست از قبل ساخته شده است:
- ایمیل: `test@economy.local` — رمز: `Test@12345` (خانواده: «خانواده تست»)

برای اینکه بابا/مامان روی گوشی خودشان وارد شوند (حداکثر ۳ عضو)، روی کامپیوتر:
```powershell
cd backend
.venv\Scripts\python.exe manage.py shell -c "from django.contrib.auth import get_user_model; from apps.families.models import FamilyGroup, FamilyMembership; u = get_user_model().objects.create_user(email='baba@economy.local', password='Baba@12345', full_name='Baba'); FamilyMembership.objects.create(family=FamilyGroup.objects.get(name='خانواده تست'), user=u, role='member')"
```
بعد در اپ: «تنظیمات ← کارت‌ها و حساب‌ها» → کارت را ثبت کن و «بابا» را از اعضا انتخاب کن.
از آن به بعد تراکنش‌های آن کارت فقط روی گوشی بابا قابل ویرایش/دسته‌بندی است و بقیه فقط می‌بینند.

## ۴) چه چیزهایی را تست کن
- [ ] **پیامک وقتی اپ بسته است:** اپ را ببند، یک پیامک بانکی بیاید، پیامک را از صندوق پاک کن،
      بعد اپ را باز کن → تراکنش هست (به‌محض رسیدن ذخیره شده بود).
- [ ] بالای صفحه: ماه شمسی + «از ۱ … تا ۳۱ …»؛ فلش راست = ماه قبل.
- [ ] «کارت‌ها و حساب‌ها»: کارت بابا/مامان را ثبت کن → تراکنش‌ها زیر نام همان شخص و کارت می‌روند.
- [ ] نمای «افراد و کارت‌ها» (پله‌ای) و «همه با هم» (با سرتیتر روز)؛ «ترتیب»: جدیدترین/بیشترین مبلغ…؛ «فیلتر».
- [ ] لمس طولانی روی یک تراکنش → انتخاب چندتایی → دسته‌بندی گروهی یا «نامعتبر».
- [ ] ضربه روی تراکنش → جزئیات + «متن پیامک اصلی»؛ دسته‌بندی/ویرایش/«نامعتبر است».
- [ ] «منتظر دسته‌بندی» فقط تراکنش‌های از ۱ مهر ۱۴۰۵ به بعد را نشان دهد (در تنظیمات قابل تغییر).
- [ ] «بازبینی»: فقط پیامک‌های مبهم/ناموفق، با دلیل و متن پیامک.
- [ ] «گزارش و نمودار»: روند روزانه (هزینه/درآمد)، تفکیک افراد/کارت‌ها/دسته‌ها؛ آیکون PDF → اشتراک یا چاپ.
- [ ] «تنظیمات ← همگام‌سازی الان» → پیام «N ارسال، M دریافت». با سرور خاموش → پیام
      «سرور در دسترس نبود…» و تراکنش‌ها در صف می‌مانند؛ سرور را روشن کن و دوباره بزن.
- [ ] گوشی دوم با حساب بابا → تراکنش‌های کارت بابا قابل ویرایش، بقیه با قفل (فقط دیدنی).

## نکته‌ها
- این نسخه برای تست روی شبکه‌ی خانه HTTP بدون TLS را مجاز می‌کند و با کلید debug امضا شده.
  نسخه‌ی تولیدی روی VPS با HTTPS خواهد بود.
- متن پیامک‌ها فقط روی خود گوشی ذخیره می‌شود و هرگز به سرور نمی‌رود.
- ساخت دوباره‌ی APK: `cd mobile && flutter build apk --release --split-per-abi`.
- تست زنده‌ی همگام‌سازی با سرور واقعی (دو گوشی شبیه‌سازی‌شده): `mobile/test_live/` — روش اجرا در سرِ فایل.
