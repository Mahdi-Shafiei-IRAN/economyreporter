# اجرای اپ روی گوشی خودت (سرور = کامپیوتر خودت)

## پیش‌نیاز شبکه
- گوشی و کامپیوتر روی **یک Wi-Fi** باشند.
- IP کامپیوتر: **192.168.1.100** (اگر عوض شد با `ipconfig` ببین؛ بعد یا در
  `mobile/lib/core/config/app_config.dart` عوضش کن یا موقع بیلد
  `--dart-define=API_BASE_URL=http://<IP>:8000/api/v1` بده و دوباره بساز).

## ۱) اجرای سرور روی کامپیوتر
```bash
cd backend
.venv\Scripts\python.exe manage.py runserver 0.0.0.0:8000
```
اجازه‌ی عبور فایروال برای پورت ۸۰۰۰ (PowerShell با دسترسی Administrator، یک‌بار):
```powershell
New-NetFirewallRule -DisplayName "Django Dev 8000" -Direction Inbound -LocalPort 8000 -Protocol TCP -Action Allow
```
تست از خود گوشی: در مرورگر گوشی باز کن
`http://192.168.1.100:8000/api/v1/auth/me/` → باید یک JSON با خطای 401 بدهد.
اگر باز شد یعنی گوشی سرور را می‌بیند.

## ۲) نصب APK روی گوشی
- فایل ساخته‌شده: `mobile/build/app/outputs/flutter-apk/app-debug.apk`
- روش A (کابل USB): حالت Developer + USB Debugging گوشی را روشن کن، سپس:
  ```bash
  adb install -r mobile/build/app/outputs/flutter-apk/app-debug.apk
  ```
  (adb در `C:\Users\mahdi\AppData\Local\Android\sdk\platform-tools\adb.exe`)
- روش B (بدون کابل): فایل apk را به گوشی منتقل کن (تلگرام/USB/…)، روی گوشی
  «نصب از منابع نامطمئن» را برای فایل‌منیجر مجاز کن و نصب کن.

## ۳) ورود
کاربر تست از قبل ساخته شده است:
- ایمیل: `test@economy.local`
- رمز: `Test@12345`

## ۴) چه چیزهایی را تست کن
- [ ] ورود موفق → رفتن به داشبورد.
- [ ] «افزودن پیامک»: فرستنده + متن یک پیامک واقعی → ثبت و نمایش با مبلغ/نوع/تاریخ/کارت‌یاحساب.
- [ ] همان پیامک را دوباره اضافه کن → پیام «قبلاً ثبت شده».
- [ ] بالای صفحه: جمع درآمد/هزینه/مانده درست باشد (به تومان).
- [ ] ضربه روی یک تراکنش → ویرایش نوع/مبلغ/توضیح یا حذف.
- [ ] نشان «بازبینی» (عدد قرمز) برای پیامک‌های نامشخص → تعیین نوع + تأیید.
- [ ] دکمه‌ی همگام‌سازی (آیکون ابر) → پیام «X موفق». (سرور باید روشن باشد.)
- [ ] داشبورد خانواده (آیکون نمودار) → جمع از سرور بیاید.
- [ ] تطبیق مانده: دو پیامک پیاپیِ یک حساب با مانده‌ی ناهماهنگ → بنر «احتمال پیامک جاافتاده».
- [ ] خروج (آیکون خروج) → برگشت به صفحه‌ی ورود.
- [ ] حالت آفلاین: سرور را ببند، چند پیامک اضافه کن (ثبت محلی کار می‌کند)،
      سرور را باز کن و همگام‌سازی بزن → همه بروند بالا.

## نکته‌ها
- این نسخه **APK دیباگ** است و فقط برای تست، HTTP بدون TLS را مجاز می‌کند.
  نسخه‌ی تولیدی (release) روی VPS با HTTPS خواهد بود.
- **SMS Receiver** (خواندن خودکار پیامک از صندوق پیام) هنوز اضافه نشده؛ فعلاً
  پیامک را دستی در «افزودن پیامک» می‌چسبانی. این مرحله‌ی بعدی است.
- برای ساخت دوباره‌ی APK: `cd mobile && flutter build apk --debug`.
